### 1.3 Cara membuktikan "gagal di kode lama, lulus di kode baru" (wajib, direkam)

1. Pisahkan **dua jenis kegagalan** dan catat keduanya: (i) *modul baru gagal impor* (`ModuleNotFoundError`/`ImportError`/`AttributeError` pada nama baru) — hanya bukti keberadaan; (ii) *perilaku atas berkas lama* — tes yang mengimpor modul lama dan gagal pada asersi (inilah bukti yang bernilai).
2. Perintah: `git stash push -u -- services docker-compose.yml docker-compose.keystore.yml Makefile scripts docs README.md audit.md .env.example` (menyimpan SEMUA perubahan produksi, membiarkan `tests/` baru/berubah) → `$PY -m pytest <tes FEAT> -q 2>&1 | tee .agents/tasks/build-pipeline-2b/evidence/FEAT-<X>-lama.txt` → `git stash pop`. ## 12. Bukti sandbox ujung-ke-ujung (langkah workflow `sandbox-e2e`; WAJIB, keluaran ditampilkan di laporan)

Harness di **`/projects/sandbox/emu-2b/`** (TIDAK di-commit; dihapus di akhir). Semua proses nyata, bukan pemanggilan fungsi:

1. **Siapkan**: `DATA=/projects/sandbox/emu-2b/data` dengan volume `uploads work files db spool bench benchspool builds signspool signwork` (`chown -R 10001:10001`, kecuali kunci); keystore sementara: `keytool -genkeypair` JDK 21 lokal → `secrets/` mode 700 milik root + berkas `signing_keystore.p12`/`signing_keystore_pass` milik uid LAIN (mis. 1000) mode 644 (pola 2a, bind per-berkas). 2. **Tampilan mount per layanan** (`unshare -m --propagation private` + `mount --bind`, `-o remount,bind,ro` untuk `ro`; satu folder "view" per layanan sebagai `DATA_DIR`): runner = `uploads:ro work bench:ro builds spool`, TANPA `signspool/signwork/benchspool/files/db`; bench = `uploads:ro work:ro bench benchspool`, TANPA `builds`; signer = `builds signspool signwork` + kunci per-berkas; worker = `uploads:ro work db spool builds signspool`, TANPA `signwork/bench`; web = `uploads work files db bench benchspool builds`.
