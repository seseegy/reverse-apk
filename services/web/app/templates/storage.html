    Panduan server

    Docker, log, dan sistem berada di luar jangkauan web (aplikasi ini sengaja tidak memegang akses Docker). Jalankan perintah ini langsung di server.

    {% macro cmd(text, why) %}
    {{ why }} 
    {{ text }}
    {% endmacro %} {{ cmd('df -h /', 'Ruang disk keseluruhan') }} {{ cmd('docker system df', 'Ringkasan image, kontainer, volume, dan cache build') }} {{ cmd('docker system df -v', 'Rincian ukuran per volume dan per image') }} {{ cmd('docker builder prune --filter until=168h', 'Buang cache build yang lebih tua dari 7 hari') }}

    Perintah terakhir hanya menyentuh cache build, bukan kontainer yang berjalan, image yang dipakai, atau volume data. Efeknya, build berikutnya bisa lebih lambat.

    {{ icon('alert-triangle') }}
    Jangan jalankan docker system prune -a --volumes atau docker volume prune. Keduanya dapat menghapus volume data aplikasi (APK, hasil analisis, database) dan tidak bisa dibatalkan.
